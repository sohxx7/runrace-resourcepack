# runrace-resourcepack

runrace 마인크래프트 26.3 서버의 리소스팩입니다. 빌드마다 릴리스로 올립니다.

다음 애셋은 테일즈런너(Smilegate Megaport)의 것입니다. 비영리 팬 활동 목적으로 고객센터의 허가를 받아 무료로 배포합니다. 상업적 이용·판매에는 쓸 수 없습니다.

- 흥부놀부 맵의 배경 그림·환경음·배경 음악
- 테일즈런너 고유 캐릭터 33명의 모델(원본 3D 모델을 블록 모델로 바꾼 것)·얼굴 그림·음성
- 시작 카운트, START, GOAL, WIN, LOSE 그림과 아이템 아이콘

다른 작품과의 협업 캐릭터와 애셋은 넣지 않았습니다.
