# runrace-resourcepack

runrace 마인크래프트 26.3 서버의 리소스팩입니다. 빌드마다 릴리스로 올리며, 용량 때문에 여러 팩으로 나눕니다.

- main.zip: HUD·UI, 효과음·경기 음악, 이펙트 (server.properties 의 기본 팩)
- chars.zip: 캐릭터 몸 모델(부위별), 의상·장신구, 메뉴 아이콘
- voice.zip: 캐릭터 음성
- maps.zip: 원작 맵 배경 그림·환경음·맵 음악
(main 외의 팩은 서버 플러그인이 접속할 때 함께 보냅니다.)

테일즈런너(Smilegate Megaport)의 캐릭터·UI·사운드·맵 애셋을 비영리 팬 활동 목적으로 고객센터의 허가를 받아 무료로 배포합니다. 상업적 이용·판매에는 쓸 수 없습니다.
다른 작품과의 협업 캐릭터(케로로, 짱구, 명탐정 코난, 슈가슈가룬, 캐릭캐릭체인지, 잔망루피 등)는 그 작품의 저작권이 있어 넣지 않았습니다.
