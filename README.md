# runrace-resourcepack

runrace 마인크래프트 26.3 서버의 리소스팩입니다. 빌드마다 릴리스로 올리며, 용량 때문에 여러 팩으로 나눕니다.

- main.zip: HUD·UI, 효과음·경기 음악, 이펙트 (server.properties 의 기본 팩)
- chars.zip: 캐릭터 몸 모델(부위별), 의상·장신구, 메뉴 아이콘
- voice.zip: 캐릭터 음성
- maps.zip: 원작 맵 재질 블록·배경 그림·환경음·맵 음악
(main 외의 팩은 서버 플러그인이 접속할 때 함께 보냅니다.)

테일즈런너(Smilegate Megaport)의 캐릭터·UI·사운드·맵 애셋을 비영리 팬 활동 목적으로 고객센터의 허가를 받아 무료로 배포합니다.
외부 IP와의 협업 캐릭터도 같은 기준(비영리 개인 사용·순수 팬 활동, 무료 배포)으로 사용할 수 있다는 답변을 받았습니다.
협업 캐릭터의 원작 권리는 각 원작사에 있습니다. 상업적 이용·판매·유료 아이템에는 쓸 수 없습니다.
